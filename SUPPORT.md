# Support

Run `workcopy doctor` and read [troubleshooting](docs/troubleshooting.md) first. For reproducible defects, use the bug-report issue form with a small synthetic repository. Include the exact command, exit code, expected behaviour and platform versions.

Do not attach your entire work repository, credentials, private conflict content or a raw home directory. Replace sensitive paths in diagnostics. Security problems follow [SECURITY.md](SECURITY.md), not public issue reports.

The project does not provide paid support or guaranteed response times.
