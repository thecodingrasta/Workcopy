# VS Code / GitHub Copilot setup

This adapter installs canonical skills under `.github/skills/` and supplies a VS Code `.vscode/mcp.json` example. Merge the `servers.workcopy` entry into an existing file; never replace other MCP servers. The Workcopy executable must be available on the VS Code agent host's PATH.

The portable Agent Plugin package is the preferred bundle where the installed VS Code/Copilot version supports it. Git-hosted plugin marketplaces are repository-based and are not a single centrally reviewed public directory.
