# Workcopy skills-only package

This is a separate skills-only plugin identity for OpenAI directory publication when local MCP submission eligibility is unavailable. It does not bundle or connect the Workcopy MCP server. Users must install Workcopy and configure its local MCP server separately. Do not later add MCP to this published skills-only listing; OpenAI's current submission flow requires an MCP server to be included in the initial submission.

For the combined local stdio MCP and skills package, submit `workcopy_agent_plugin` only after the submitting organization is confirmed eligible and allowlisted for local MCP.
